# 🌐 Free GitHub Pages Hosting for ROZ Monitor (1-Minute Setup)

You can host your permanent mobile web portal for free forever on GitHub Pages.

---

### Instructions:
1. Create a new GitHub repository (e.g. `roz` or `roz_monitor`).
2. Upload the 3 files in this folder (`index.html`, `manifest.json`, `sw.js`).
3. Go to **Settings** -> **Pages** in your GitHub repository.
4. Under **Branch**, select `main` (root) and click **Save**.
5. GitHub will give you your permanent URL:
   `https://<your-github-username>.github.io/roz/`

---

### That's it!
All players can now pair with your permanent portal URL once and access their live monitor forever!
